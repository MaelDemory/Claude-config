## Seconde passe (trouvé après les changements)

- Les règles `deny Read(**/.env)` ne couvrent pas `cat .env` en Bash, d'autant plus avec `cat:*` en allow → hook `guard-secrets.sh`.
- `defaultMode: acceptEdits` dans le template aurait dégradé les sessions en mode auto → retiré ; recommandation : mode auto.
- `install.sh` ne propageait jamais les nouveaux hooks sur un poste déjà installé → fusion additive et idempotente des hooks et des règles allow/ask/deny.
- `install.ps1` écrivait `settings.json` avec un BOM sous PowerShell 5.1 → écriture UTF-8 sans BOM.
- Mémoire native Claude Code et vault sans frontière → règle de partage dans le harnais.
- Les règles de permission préfixées ne voient peut-être pas la commande réécrite par rtk (`rtk git push …`) → variantes `rtk …` ajoutées dans `ask`/`deny`.

## Pistes restantes

- **Commits autonomes** sur branche de travail : non activés (bloqués par le garde-fou d'auto-modification) ; décision utilisateur requise.
- `check.sh` : vérifier que chaque skill/agent cité dans le harnais existe.
- Hook `Stop` de type vérification (bloquer la fin d'une tâche medium/large sans check exécuté) — utile mais risque de boucle ; à tester sur un projet.
- Restreindre `planner` par `tools:` (il ne doit écrire que des `PLAN-*.md`) — aujourd'hui seulement en consigne.

## Révision : `lessons.md` + esprit Karpathy

- **Harnais** réécrit autour de 4 principes : réfléchir avant de coder (hypothèses explicites, questions *avant* le code), simplicité, changements chirurgicaux, exécution pilotée par des critères vérifiables (boucle autonome, arrêt après deux échecs).
- **Mémoire projet** : un seul fichier `lessons.md` à la racine du repo, injecté à chaque session par `session-context.sh` ; Claude y ajoute une règle après chaque correction. Remplace le vault, `PROGRESS.md`, `DECISIONS.md`, `feature_list.json` et `TASK_CONTEXT.md` ; seuls les `PLAN-*.md` restent pour les gros chantiers.
- **Supprimés** : agents `vault`, `kanban`, `indexer`, `cartography`, `file-system` ; skills `vault-search`, `memory-write`, `kanban-*`, `create-project`, `onboard-project`, `project-sumup`, `start-session`, `cartography-map`, `create-index`, `create-doc`, `write-agents-md`, `file-search` ; `scripts/vault-bootstrap.sh`. Restent 8 agents et 14 skills.
- **Adaptés** : `create-plan` (étapes `→ verify:`, leçons appliquées), `wrap-up` (section Lessons), `ship`, `planner`, `review` (contrôle « chaque ligne se rattache à la demande » + respect de `lessons.md`).
- **Installeur** : retire les symlinks orphelins pointant dans le repo (sh et ps1).
- Les skills optionnelles `content-*` lisent toujours leurs guides dans `~/Documents/ObsidianMemory/Content Vault/guides/` — à revoir si elles sont réactivées.
